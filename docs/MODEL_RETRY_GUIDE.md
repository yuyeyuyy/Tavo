# 模型重试与单次生成上限

本轮无需 init 或数据库迁移。停止旧后端后执行 `pnpm dev:backend`，重启客户端 `pnpm dev`；已有模型与 Key 保留。默认重试策略随后端进程启动生效，不需要修改正常数据。

## 自动重试

文本回复、Agent 一轮模型请求、模型自审查共享策略：初次请求后最多重试3次，合计至多4次。只有模型 HTTP 请求会重发，不重新插入用户消息或执行已完成的工具。

受控重试包括临时连接/读取故障、408、429（已识别的配额耗尽除外）、500/502/503/504、DeepSeek生成中断与正常空回复。鉴权、余额不足、参数/模型错误、404、拒绝/过滤、非法数据和敏感响应校验失败停止。正常有正文但 length 的结果仍作为截断回复展示；不重试截断的工具参数，不自动换厂商或关闭思考。

对于官方已确认的 deepseek-flash/deepseek-v4-pro，显式保留思考。若 length 且无正文/完整工具调用，当前2048初始配置按2048→4096→8192→16384增加每次预算；达到策略上限或尝试次数后停止。其他模型不会自动获得这些专属参数或增额，存储的初始预算和8192约束不变。

## 时间与费用边界

全部重试共用原有模型60秒、模型审核30秒以及Run剩余总时间；停止/断线/取消仍立即传播。上限不是保证一定做满三次重试，慢任务可能先超时。

真实验收中，一个较小的CSV合成任务在2048思考耗尽后，4096重试得到完整未截断正文；复杂执行池设计任务则在第三次尝试触及60秒而停止。不会为了生成成功无限等候或偷偷关闭思考。账户余额与单次生成/时间上限是不同限制，每次重试可能再次计费，不能保证上游取消后不计费。

## 管理员配置

使用启动后端的同一终端环境；backend/.env.example 只是说明，不自动加载。以下均有默认值，通常不需要设置：

| 变量 | 默认 | 范围/含义 |
| --- | --- | --- |
| TAVO_MODEL_MAX_RETRIES | 3 | 0–3，0表示关闭自动重试 |
| TAVO_MODEL_RETRY_MAX_OUTPUT_TOKENS | 16384 | 128–16384，仅为支持模型的重试生成上限，不降低原初始预算 |
| TAVO_MODEL_RETRY_DELAY_SECONDS | 0.25 | 0–5秒，异步指数退避基数 |
| TAVO_MODEL_RETRY_MAX_DELAY_SECONDS | 5 | 0–10秒，退避/Retry-After可接受上限 |

合法 Retry-After 不会被截短后提前请求；超出等待上限或剩余时间则停止。配置非法时启动失败，不静默放开限制。

## 定位链路

后端 Uvicorn INFO 日志中的 `model_request` 包含独立的 `call` 诊断标记、kind、stage、attempt、output_budget、http_status、允许的finish_reason、用量、正文/思考存在标志、outcome、error_code及耗时。

stage=transport 是连接/发送；read 是响应头/读取；parse 是JSON与模型协议结果；retry_wait 是等待中取消。相同call标记关联一轮内多次尝试，它不是Session或凭据ID。日志不保存Key、正文、私有思考、请求/响应对象或原始异常。usage只包含上游提供的计数；公开成功回复usage仍是最后一次响应，并非整个重试过程的账单总额。

- MODEL_OUTPUT_LIMIT：单次生成上限耗尽，仍没有正文。
- MODEL_EMPTY_RESPONSE：正常结束但回复为空。
- MODEL_REJECTED：上游拒绝/过滤，或原有接口不接受该响应内容。
- MODEL_TIMEOUT：本轮等待时间已耗尽。

这些诊断只覆盖当前进程日志；没有新持久调用审计表。Worker重启后对未知在途请求仍保持中断，不自动重放。实施与真实限制见 [MODEL_RETRY_OUTPUT_REPORT.md](MODEL_RETRY_OUTPUT_REPORT.md)。
