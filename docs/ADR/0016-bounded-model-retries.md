# ADR0016：模型请求的有界重试与输出预算

日期：2026-11-17。用户已确认 MODEL_RETRY_OUTPUT_PLAN.md，已实施。

DeepSeek HTTP200的2048生成token全部用于思考，公开正文为空，旧解析器却抛MODEL_REJECTED。合成对照与生产网关均已复现。用户要求最多重试3次，同时明确禁止重发原对话。

可选方案是关闭思考，或保留思考并在耗尽时增加有界预算。选择后者：支持的DeepSeek模型明确thinking.enabled，仅length且无公开正文/完整工具调用时扩大预算，至多16384。数据库profile仍是原初始预算，避免迁移和隐式覆盖配置；每次预算覆盖仅由后端策略传入，不接收客户端值。

ModelGateway复用一个HTTP/读取/解析尝试与重试循环。ModelRetryPolicy是小型纯策略，Settings从环境读取并由Services注入同一网关，因此文本、Agent与自审查共享规则。初次加最多3次重试，可恢复错误短异步退避；配置/鉴权/明确拒绝/非法数据不重试。重试不新建消息、逻辑轮次、Decision或工具执行；正常文本截断和完整工具调用仍沿用原流程。

重试不能越过现有60秒模型、30秒审核和Run预算。取消能中断读取和退避，流上下文负责关闭连接。Worker崩溃的未知请求不自动重放，不声称外部Exactly-once或取消不计费。

生成上限耗尽与普通空回复分为新错误码，旧拒绝/接口不支持响应维持兼容。仅记录白名单安全元数据及独立诊断标记，不记录正文、Key、思考或原始异常；暂不引入数据库审计表。API生成结果字节不变，TS/Zod公共错误表同步更新，无新依赖或迁移。

实际验证包含确定性网关/Agent集成、取消/预算、桌面与包内流程，以及两次真实合成逻辑请求；一项复杂任务触及60秒，另一项在4096重试后完整成功。详见 [验收](../MODEL_RETRY_OUTPUT_REPORT.md)。
