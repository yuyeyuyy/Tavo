# ADR 0005：客户端收敛为单页对话

状态：已采用，2026-11-14；用户确认 CHAT_CLIENT_PLAN.md 方案 A。

用户希望客户端先只保留类似 Grok 的对话形式。选择重写 Renderer 为深色单页聊天，移除五个业务页面，连接配置收进弹窗。另一方案是同时建设真实聊天后端，但这需要会话存储、模型/费用与流式协议，不属于本轮确认范围。

UI → 内存会话 store → 可注入 ChatTransport；首轮使用明确标注的本地 Mock。后端原 analyze(eventId) 不是聊天接口，不把任意消息写入它，也不把聊天自动当长期记忆。Python Agent 基础设施和数据保留，未来通过正式协议接入。

停止用 AbortSignal 发出取消请求，并用每次不同的 requestId 丢弃晚到结果；新对话清空本地会话。重试不重复用户消息，异常不回显原始内容。无 localStorage 或会话数据库，重启清空聊天是本轮明确行为。

连接弹窗沿用原生配置/认证，Renderer 无凭据输入或读取；不扩大六方法桥接/CSP。窗口尺寸和标题栏只服务于对话布局。后果是原账户/活动/偏好管理暂时没有 UI 入口，仍可使用受认证的后端 API；不能将 Mock 界面称为真实 Agent 聊天。
