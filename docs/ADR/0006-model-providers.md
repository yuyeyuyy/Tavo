# ADR 0006：多厂商聊天适配与服务端模型凭据

状态：已采用，2026-11-16；用户确认 MODEL_PROVIDERS_PLAN.md 推荐范围。

采用四类薄协议适配器和九家厂商预设，复用锁定版本 httpx，升为运行依赖。另一方案是安装每家 SDK 或引入统一网关库；本轮只有受限非流式文本，前者增加默认重试/日志/依赖边界，暂不选择。

模型 Key 在服务端终端隐藏输入，复用现有 SecretStore 加密与外部密钥环。替代方案是后端环境注入，适合部署但本轮优先本机多厂商配置。JSON 仅存非秘密 profiles，不允许前端提交 Key、Base URL 或系统身份；模型 Key 引用绑定厂商与目标地址，避免地址变更自动带旧凭据。

新增认证 Chat API，不将聊天发送给 analyze(eventId)，不自动注入账户数据/记忆或工具。首轮保持窗口内存会话、每次发送有界历史；无 streaming、持久 conversation/thread、自动重试或跨厂商 fallback。代价是长对话需新开、部分推理模型可能耗尽预算没有公开文本，需用户选择合适模型/预算。

客户端显式选择模型，切换即开始新对话；失败明确显示而不伪装 Mock 成功。模型取消只能保证本地停止接收并尝试取消上游，不能承诺停止计费。厂商兼容声明由官方协议和合成契约验证支持，真实账户成功须由用户逐家本地确认。
